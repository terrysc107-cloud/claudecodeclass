Every project you build with Cursor is also an asset. Extract the pattern into a reusable template and you can sell it, speed up future projects, and build a catalog of sellable products from work you're already doing.

## What Makes a Good Template

A template is not just "the code." A good template includes:

- **The working codebase** — clean, documented, production-ready
- **A `.cursorrules` file** — so any developer who uses it can get productive immediately
- **Environment variable documentation** — what each variable does and where to get it
- **A setup guide** — step-by-step from clone to deployed
- **A demo or screenshots** — so buyers can see what they're getting

The `.cursorrules` file is what separates a professional template from a raw code dump. It tells Cursor what the project is, how it's structured, and how to add to it — making the template immediately useful for AI-assisted development.

<Callout type="tip">
After finishing any project, take 30 minutes to turn it into a template: remove client-specific data, extract hard-coded values to environment variables, write a setup guide, add a .cursorrules file. That 30 minutes can generate passive income for months or years.
</Callout>

Build templates systematically:

1. Next.js SaaS starter (auth + payments + Supabase)
2. Landing page template (multiple sections, easy to customize)
3. API wrapper service (Next.js + third-party API integration)
4. Dashboard template (data tables, charts, navigation)

Each new client project that fits a pattern becomes a template. Your catalog grows automatically from client work, and each product generates passive income.

## GitHub Template Repos

For developer-focused templates, mark your GitHub repo as a "Template repository" in Settings. This adds a "Use this template" button that creates a clean copy with a single click — no fork, no git history clutter.

This is exactly how the course platform you're using was built. It's already a template repo that anyone can clone and deploy for their own course.
