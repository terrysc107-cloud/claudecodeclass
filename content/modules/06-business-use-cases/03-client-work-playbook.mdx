Claude Code doesn't just make you faster — it changes your economics. When you can deliver in days what used to take weeks, you face a choice: lower your prices or raise your rates. The right answer is obvious.

## Scoping With Claude Code in Mind

When scoping a project, estimate delivery time with AI assistance — not without. If a feature would take you 8 hours without AI, with Claude Code it might take 2–3 hours.

Your rate should increase to reflect this, not decrease. Clients pay for the outcome. A working product in 3 days is worth the same to them as a working product in 3 weeks — or more, because it's faster.

## The Discovery Session

Before quoting, do a discovery session with the client. Then use Claude Code to analyze the scope:

```
A client wants to add a customer portal to their SaaS.
Features: customers can view invoices, update billing info,
manage their subscription, and download usage reports.
They use Stripe already. The backend is a Next.js API.

What's the scope of this work? What are the major pieces,
what dependencies need to exist first, and what are the
most likely sources of scope creep?
```

Use Claude's analysis to ask the right questions, catch scope creep before it starts, and build a realistic timeline.

<Callout type="info">
Scope creep is the number one killer of profitable client projects. Use Claude Code to document exactly what's in and out of scope in writing before you start. A simple Google Doc with a feature list and explicit exclusions ("does not include mobile app", "does not include data migration") protects you and sets clear expectations.
</Callout>

## Per-Client CLAUDE.md

For every client engagement, create a `CLAUDE.md` that captures their stack and conventions:

```
## Client: Acme Corp
## Project: Customer portal addition to their SaaS

## Existing Stack
- Next.js 14 (not 15 — do not use new APIs)
- PostgreSQL via Prisma ORM
- Stripe for payments

## Their Conventions
- All components use class components (legacy codebase)
- API responses use the format: { data: {}, error: null }
- All monetary amounts in cents

## Be Extra Careful About
- The auth system is custom (not NextAuth) — ask before touching
- Never modify the Prisma schema without explicit discussion
```

This produces code that fits their codebase instead of code they have to adapt.

<Callout type="tip">
When you hand off code that matches the client's patterns and conventions, they trust you. When you hand off code that works but looks foreign, they worry. The CLAUDE.md file costs 10 minutes to set up but earns referrals.
</Callout>

## Getting Up to Speed on a Client Codebase

When taking on a new client project, use Claude Code to accelerate onboarding:

```
Read the following key files and give me an orientation to this codebase:
[list the main entry points, config files, and core modules]

I need to understand: the main data models, the auth flow,
the deployment setup, and the areas of highest complexity or risk.
```

What would normally take days of reading code can be condensed into an hour of structured questions.

## Delivering and Handing Off

On delivery, provide:

1. A working demo with the features tested
2. A brief summary of what was built and any decisions made
3. Clear documentation of environment variables and setup steps
4. A "how to maintain this" note if they'll be doing updates themselves

Use Claude Code to generate documentation:
```
Write a brief handoff document for this feature.
Include: what it does, how it works at a high level,
environment variables required, and common issues and fixes.
```

This takes 5 minutes and dramatically improves how clients perceive the quality of your delivery.

## The Rate Conversation

When clients balk at your rate after learning you use AI tools: "AI makes me faster and more consistent, which means you get a better result in less calendar time. The alternative is paying me less for slower work with more risk. That's the wrong trade."

<KeyPoint>Claude Code compresses delivery time — your job is to price based on value delivered, not hours spent. A client who waits 3 days instead of 3 weeks for a working product is getting more, not less.</KeyPoint>
