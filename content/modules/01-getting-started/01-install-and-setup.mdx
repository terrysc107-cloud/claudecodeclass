Cursor is a code editor built on top of VS Code — which means your existing extensions, themes, and keyboard shortcuts transfer over the moment you install it. The only thing that changes is what happens when you press a few specific keys.

## Download and Install

Go to [cursor.com](https://cursor.com) and download the installer for your operating system. The install is standard: run the installer, open the app.

When you first launch Cursor, it will ask if you want to import your VS Code settings and extensions. Do it. Your environment will look identical to VS Code within seconds.

## Connect Your AI Model

Cursor ships with access to several models: Claude Sonnet, GPT-4o, and others. By default it uses its own managed API. You can also bring your own key (BYOK) from Anthropic or OpenAI if you have high usage.

For most users: stick with the default managed access. No configuration needed.

## The VS Code Foundation

Because Cursor is built on VS Code, everything you already know applies:

- All your keybindings work unchanged
- Your installed extensions carry over
- Your color theme and font settings are preserved
- The file explorer, terminal, and git panel are identical

The only additions are the AI-specific panels: Chat (Cmd+L), Composer (Cmd+Shift+I), and inline editing (Cmd+K). We'll cover all three in the next lessons.

<Callout type="info">
Cursor keeps pace with VS Code updates, so you won't fall behind on editor features. The core editor is essentially the same — just with AI wired in at every layer.
</Callout>
