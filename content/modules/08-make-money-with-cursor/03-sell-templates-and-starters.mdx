Templates are the highest-margin product a developer can sell. You build them once from work you were already doing, and they sell indefinitely with no additional time investment. Claude Code adds a new category of sellable asset that didn't exist before: the `CLAUDE.md` template itself.

## What Sells

**SaaS starter templates** ($97–$197)
The full scaffold: auth, payments, database, deployment. A developer can clone it and have a working foundation in minutes instead of days. These sell because they save significant setup time on every project.

**Landing page templates** ($29–$97)
Clean, conversion-optimized Next.js or React landing page with multiple sections and easy customization. Every business needs a landing page. Developers who don't want to design from scratch will pay.

**Niche-specific starters** ($49–$197)
A starter configured for a specific use case: a course platform, a job board, a directory site, a client portal. More specific = higher price for the right buyer.

**Automation scripts** ($19–$49)
Python or Node scripts that solve a specific recurring problem: CSV processing, API data sync, scheduled reports. Low price, high volume potential.

**CLAUDE.md configuration packs** ($9–$39)
Collections of well-crafted `CLAUDE.md` files for specific stacks, frameworks, or project types. Surprisingly in demand among developers who use Claude Code but haven't built good configurations yet. This is a uniquely Claude Code product category — it didn't exist before.

## The CLAUDE.md as a Product

A `CLAUDE.md` template for a specific stack or workflow is something you can sell on its own. Developers using Claude Code know that a well-crafted `CLAUDE.md` dramatically improves their output quality — but most haven't invested the time to write really good ones.

What makes a CLAUDE.md template worth paying for:

- Specific, accurate architecture documentation for the framework
- Opinionated conventions that reflect genuine best practices
- "Do not" rules that prevent common AI-generated mistakes for that stack
- Domain context for specific industries or use cases
- Prompt snippets for common tasks in that framework

A pack of 10 well-crafted `CLAUDE.md` files — one each for Next.js SaaS, Django REST, React Native mobile, Python automation, FastAPI backend, etc. — is a legitimate product. The person buying it gets hours of context-engineering work for $29.

## Preparing a Template for Sale

1. **Remove all client-specific data** — no client names, no real API keys, no hardcoded business logic
2. **Extract everything to environment variables** — all secrets, URLs, and configuration
3. **Polish the `CLAUDE.md`** — this is the key differentiator for developer-focused templates; make it exemplary
4. **Write a setup guide** — from `git clone` to deployed in the simplest possible steps
5. **Add screenshots or a demo** — buyers need to see what they're getting
6. **Write a clear description** — what does this solve, who is it for, what's included

The `CLAUDE.md` quality is what separates a professional template from a raw code dump. It tells any developer using Claude Code how to work in the project immediately.

## Marketing Templates

Without an audience, templates are hard to sell by sitting on a marketplace. They need to be discovered. Channels that work:

- **X / Twitter** — post a thread about how you built it, what problems it solves, link to purchase
- **Reddit** — post in relevant subreddits (r/ClaudeAI, r/nextjs, r/webdev) — be genuinely helpful, mention the template where relevant
- **YouTube** — a short video tutorial about the problem the template solves, with a link to the template in the description
- **Communities** — Discord servers, Slack groups, niche forums where your target buyer hangs out

<Callout type="info">
Content about the problem drives more sales than content about the product. "How to set up Stripe webhooks in Next.js" attracts people who then discover your SaaS starter template. Solve their problem for free in a blog post or video, then sell them the shortcut. The same applies to CLAUDE.md templates: "How to write a better CLAUDE.md" is a piece that naturally leads to "...or buy mine."
</Callout>

## GitHub Template Repos

For developer-focused templates, mark your GitHub repo as a "Template repository" in Settings. This adds a "Use this template" button that creates a clean copy with a single click. The paid version of the template lives on your storefront; the GitHub template repo is the mechanism buyers use to start their project.
